# Frederik Berg

I'm a Security Analytics Consultant at SVA in Aachen. I build and run SOC and SIEM platforms on the Elastic Stack: infrastructure and detection rules as code, automated operations, and the reporting around them. Before that I did research at the Chair for Embedded Software at RWTH Aachen on the functional safety of interconnected medical devices.

Outside work I run a small Kubernetes homelab on Hetzner for family and friends, watched by an Elastic SIEM and operated by AI agents I build myself. I co-organise the Effective Altruism group in Aachen, and I spend the rest of my time bouldering, cycling and hiking.
